# Інструкції для Claude

Статичний сайт для GitHub Pages: чистий HTML/CSS/JS, без збірки й залежностей. Власник редагує його промптами з різних комп'ютерів і часто прямо в GitHub, а файли завантажує через веб-інтерфейс GitHub.

- Весь контент лежить у `content.js` (`window.SITE`). Зміни тексту, посилань, проєктів, таймлайну тощо роби там, а не в HTML.
- Рендеринг у `assets/js/main.js` (header/footer/home/about/project), стилі в `assets/css/style.css`.
- Картинки та відео лежать у `assets/images/`. Користувач завантажує файли через GitHub UI, тому перед тим, як прописати шлях у `content.js`, перевір, що файл справді є в репозиторії, і звір точну назву й регістр розширення.
- Нові проєкти: додай об'єкт у `SITE.projects` з унікальним `slug`. Сторінка відкривається як `project.html?p=<slug>`, окремий HTML не потрібен.
- Будь-які шляхи лише відносні (`assets/...`), без провідного `/`, бо сайт живе в підпапці `/<repo>/`.
- Не додавай збірку, npm чи фреймворки. Сайт має працювати як є на GitHub Pages.
